# 品牌快闪体验设计 Agent（智能体）

面向小型创意团队中的体验设计师与创意策划，将客户需求和受众文化研究整理为有依据、可讨论、可编辑的早期品牌快闪体验提案。正式产品名待定。

当前保存的是阶段实现：官方运行时接入、本地产品工作台、工具反馈修复及提案契约修复。**完整产品尚未验收通过**。默认离线演示使用模拟模型与合成夹具，不代表真实模型成功。

完整定位与范围以 [PRODUCT.md](docs/PRODUCT.md) 为准，精简验证结论见 [VALIDATION.md](docs/VALIDATION.md)。

## 本地使用

需要 Node.js（运行环境）22.19 或更新版本。在仓库根目录执行：

```powershell
npm ci
npm start
```

离线演示不需要模型或 Qloo 密钥。打开启动时显示的本地地址，在页面载入明确标注的合成演示需求，开始探索、回答追问，再并排审阅两套概念。可选择查询失败与证据不相关的离线验收场景。

默认地址为 [本地工作区](http://127.0.0.1:3000)。当前已安装依赖时直接 `npm start` 即可。离线模型是确定性的验收替身，只展示规定场景；它不具备理解任意客户需求并生成真实研究概念的能力。

页面中的文化证据、设计推断和未验证效果分别展示。合成夹具不是 Qloo 返回，亲和关联不能解释为审美分、销量或成功率。

```powershell
npm test
```

测试使用合成数据和本地模拟传输，不发起真实模型或Qloo请求，不运行静态检查，也不依赖本机历史验证材料。测试可能生成本地合成验收记录，该目录由Git（版本控制）排除。

## 运行边界

- 使用 `@qloo/qloo-harness@0.1.26` 官方 Node（运行环境）公开会话接口，工具执行循环由官方运行时负责。
- 需求、约束、证据、概念和处理状态保存在服务端项目记录中。聊天记录不作为唯一数据源；本轮不承诺跨进程恢复。
- 项目标识由服务端绑定，模型不得提交；执行器核对版本、证据归属、实际字段和值及字面约束。双概念无追问时可以省略问题列表或使用空数组。
- 真实模式需要明确的产品提供商、模型、API（应用程序接口）协议、端点与Qloo配置，并单独授权调用预算。仅有某个密钥环境变量不代表配置齐备。
- 空值模板见 [.env.example](.env.example)，默认关闭真实模式。密钥只在本机服务端配置，不写入源码、页面或仓库。默认硬上限为每项目模型与Qloo各6次HTTP（网络）请求、每服务进程各12次，包含重试并拒绝自动跳转。一次验证可以采用更小的独立上限；已记录的复用证据验证为模型3次、Qloo 0次，不构成新的调用授权。
- 当前不包含完整局部修订、审查批准、导出、图像生成或长期记忆。本仓库没有自动部署流程；推送仍可能受托管平台的外部Git集成影响，不能只凭没有部署文件判断没有部署影响。
